=======================================================================
           DATASET PRAKTIK ERPNEXT - INDUSTRI MANUFAKTUR
                     PT SHANTI MANUFAKTUR MANDIRI
=======================================================================

Folder ini berisi seluruh dataset dan panduan lengkap untuk latihan
simulasi ERPNext pada tipe industri manufaktur (Furniture/Mebel).

DAFTAR FILE DI DALAM FOLDER INI:
---------------------------------
1. PANDUAN_PRAKTIK_MANUFAKTUR_ERP_SHANTI.docx & .md
   -> Dokumen Word & Markdown konsep bisnis, alur proses manufaktur,
      dan struktur perhitungan biaya HPP.

2. 09_Skenario_Simulasi_Transaksi.docx & .md
   -> Dokumen Word & Markdown lembar latihan transaksi step-by-step
      (Beli Bahan -> Produksi / Work Order -> Jual -> Laporan).

3. 01_Master_Item.csv
   -> Data Master Barang (Bahan Baku & Produk Jadi Meja/Kursi).

4. 02_Master_Supplier.csv
   -> Data Master Pemasok (Kayu, Logam/Besi, dan Cat/Kimia).

5. 03_Master_Customer.csv
   -> Data Master Pelanggan (Toko Mebel, Sekolah, Studio).

6. 04_Master_Workstation.csv
   -> Data Stasiun Kerja / Mesin Pabrik beserta tarif biaya per jam.

7. 05_Master_Operation.csv
   -> Data Operasi Produksi (Potong, Rakit, Cat).

8. 06_BOM_Komponen_Bahan.csv
   -> Resep Bahan Baku (Bill of Materials) untuk 1 Unit Meja Belajar.

9. 07_BOM_Operasi_Rute.csv
   -> Rute dan durasi kerja per stasiun kerja untuk 1 Unit Meja Belajar.

10. 08_Master_Gudang_Warehouse.csv
   -> Struktur Gudang (Gudang Bahan Baku, Gudang WIP, Gudang Barang Jadi).

=======================================================================
Tips: Anda dapat langsung membuka file .docx menggunakan Microsoft Word!
